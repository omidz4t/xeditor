# Screenshots

Generated by `npm run screenshots` (Puppeteer).

In CI (**Main release** / `pages.yml`), shots are captured into **`dist/screenshots/`** (gitignored), then copied into **`dist-pages/screenshots/`** for the site deploy. They are **not** committed to `main`.

## Local

```bash
npm run build:pages
npm run preview:pages   # :4173
# other terminal:
BASE_URL=http://127.0.0.1:4173 APP_PATH=/app/ OUT_DIR=docs/screenshots npm run screenshots
node scripts/build-pages.mjs
```

Or against production Pages:

```bash
npm run screenshots:pages
```

## CI (push to `main`)

1. Version bump · tag · push (bot, unsigned)  
2. Build editor + pages  
3. Puppeteer screenshots against local `dist-pages` → `dist/screenshots`  
4. Rebuild pages (shots land in `dist-pages/screenshots`)  
5. GitHub Release + deploy `gh-pages`  

No GPG keys and no screenshot commits on the main branch.

## Commands

```bash
# Local Vite (auto-start)
npm run screenshots

# Full-screen desktop (1920×1080, no crops)
npm run screenshots -- --full-screen
npm run screenshots:full

# Full-screen + entire page scroll
npm run screenshots -- --full-screen --full-page

# Production Pages layout
npm run screenshots:pages

# Subset
npm run screenshots -- --only landing-hero,app-editor
```
