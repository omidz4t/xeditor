A shared document that lives inside your chat

XEditor is a collaborative block editor packaged as a WebXDC app. You send one .xdc file in Delta Chat; everyone in the chat can open it and edit the same workspace — pages, comments, tables, images — with live presence, without signing into a website.

How it works

XEditor is not a SaaS doc. The chat carries the app and the updates. This GitHub Pages site only explains the product and hosts a solo demo — the marketing page is never packed into the .xdc.

1

Install in a chat

Download app.xdc (or full/lite font builds) from Releases, then attach or open it in a Delta Chat group or 1:1 chat.

2

Edit a shared workspace

Create nested pages, write with blocks (headings, lists, code, tables, images, polls…), leave comments on selections, and use the sidebar to navigate the tree.

3

Changes fan out in chat

Edits are stored as a Yjs CRDT and sent as WebXDC status updates. Peers merge automatically — even if someone was offline for a while.

4

See who is here

Presence shows who is online, remote cursors follow collaborators, and you can invite others to follow your view. Reactions (Alt + move) give a quick pulse without leaving the doc.

5

Import, export, save

Bring in Markdown, folders, ZIP trees, or workspace JSON. Export MD, HTML, plain text, JSON, or a fresh WebXDC. Optionally bind a local folder and save with Ctrl/Cmd+S where the browser allows.

6

Stay private

There is no XEditor backend. Delta Chat delivers messages; the document state lives in the webview (IndexedDB) and in the update stream you already trust for that chat.

Browser demo (this site)

  • Opens under /app/ with a local WebXDC mock
  • Great for trying UI, blocks, settings, import/export alone
  • Not multi-peer over real chat — use Delta Chat for that

Real multi-peer (Delta Chat)

  • Use a release .xdc inside a chat
  • Everyone opens the same app instance for that chat
  • Presence, cursors, and CRDT sync ride WebXDC updates

What you get

Editor depth that still fits a chat-sized WebXDC package.

▦

Block canvas

Headings, bullets, numbered lists, todos, toggles, quotes, callouts, code, dividers, images, page links, tables, polls — slash menu and Markdown shortcuts.

▤

Multi-page workspace

Sidebar tree, drag reorder, icons, covers, breadcrumbs, and page layout options for larger notes and wikis.

💬

Comments

Select text, start a thread, reply in the panel, jump from gutter markers back to the quote.

⌘

Keyboard-first

Command palette, formatting shortcuts, optional Vim mode, Escape stack that closes dialogs and panels in order.

ع

RTL & fonts

Direction-aware editing with Shabnam and Arad. Releases include full and lite font packs.

◎

Themes & settings

Light / dark / system, editor prefs, sync-mode setup on first open, share helpers for packaging the doc again.
