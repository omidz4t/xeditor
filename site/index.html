Built for real documents

Not a plain text box — a Notion-style block canvas with structure, media, and tools that stay useful in a chat-sized package.

▦

Block editing

Headings, lists, todos, toggles, quotes, callouts, code blocks, dividers, images, page links, tables, and polls — insert via slash menu or Markdown shortcuts.

⌘

Fast keyboard flow

Command palette, formatting shortcuts, optional Vim mode, and Escape-aware UI layers so panels close in a predictable stack.

▤

Nested pages

Multi-page workspaces with a sidebar tree, drag reorder, icons, covers, and page-level layout options.

💬

Comments & selection

Highlight text, leave threads, reply in the panel, and jump from gutter markers back to the quoted selection.

🖼

Images that behave

Upload or drop images, resize, captions, lightbox, replace/cut/copy from a context menu — built for the block canvas.

表

Tables & polls

Structured tables with cell formatting, plus lightweight polls for quick group decisions inside the document.

ع

RTL & Persian fonts

Direction-aware editing with bundled Shabnam and Arad fonts, plus full and lite WebXDC packages for size vs. completeness.

⇪

Import / export

Markdown files & folders, ZIP trees, workspace JSON, HTML, plain text — bind a local folder and save back with Ctrl/Cmd+S when the browser allows.

◎

Themes & settings

Light, dark, or system theme, editor preferences, sync mode setup, and share-to-chat packaging for WebXDC.

Collaboration without a backend

Peers sync through Delta Chat’s WebXDC channel. The document is a CRDT, so merges stay consistent even when people go offline.

Live together

  • Realtime block sync with Yjs over WebXDC updates
  • Peer presence: who is online and what they are editing
  • Remote cursors and follow invites for shared focus
  • Reactions pie (Alt + move) for lightweight acknowledgment
  • Chat-wide or per-instance sync modes when you open a doc

Private by design

  • No app server to host — the chat is the transport
  • Works as a single .xdc file you can forward
  • Local IndexedDB persistence in the webview
  • Optional folder binding for disk-backed Markdown workflows
  • Export a portable snapshot anytime (JSON / MD / WebXDC)

Demo note: the browser preview on GitHub Pages uses a local WebXDC mock. Full multi-peer collaboration shines inside Delta Chat (or make run with webxdc-dev).
